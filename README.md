# Saini Dental Hospital Website

A modern, highly-responsive, and premium website designed with a "Warm Minimal" aesthetic for **Saini Dental Hospital**, a trusted professional dental clinic located in Kota, Rajasthan.

## 🌟 Key Features

* **Warm Minimal Design:** Replacing sterile, cold clinical styles with an organic, cozy, and premium boutique look that helps reduce patient dental anxiety.
* **Modern Typography:** Styled with editorial serif (**EB Garamond**) and high-legibility sans-serif (**Plus Jakarta Sans**) font pairs.
* **Responsive Layout:** Optimized to look exceptional across desktops, tablets, and smartphones.
* **Interactive Appointment Booking:** Clean multi-step appointment scheduler that integrates seamlessly with WhatsApp for instant booking requests.
* **Complete Pages:** Includes home page, appointment booking flow, privacy policy, and terms of service.
* **SEO Optimized:** Structured semantic HTML elements and unique IDs throughout.

## 🛠️ Technology Stack

* **Structure:** Semantic HTML5
* **Logic:** Vanilla JavaScript (Vanilla JS)
* **Styling:** Tailwind CSS (Custom thematic integration for colors and shapes)
* **Icons:** Google Material Symbols (Outlined)
* **Fonts:** Google Fonts (EB Garamond & Plus Jakarta Sans)
